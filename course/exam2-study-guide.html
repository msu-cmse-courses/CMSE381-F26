    Section Exam 2 study guide

    Here we summarize the detailed learning goals in terms of a series of topics or questions that you should be able to answer by exam 2. Make sure to check out the practice problems in Exam 2 practice problems.
    🔗

    Subsection Methods of Validation

    Required readings: Chapter Section 5.1 (10 pages)
    🔗
    • Why do you need validation methods?
      🔗
      🔗
    • What is the difference between validation scores and true test errors?
      🔗
      🔗
    • What are the three most basic validation methods?
      🔗
      🔗
    • For each of these methods:
      • How do you calculate the validation score? You should be able to describe the procedures verbally and mathematically.
        🔗
        🔗
      • How do you calculate the validation score in Python?
        🔗
        🔗
      • What are the advantages and disadvantages of using this method compared to the other two methods? You should be able to describe them in terms of computational cost and the bias and variance of the estimation.
        🔗
        🔗
      🔗
      🔗
    • How do you use validation methods to select the appropriate meta-parameter?
      • Given a plot of validation score as a function of model flexibility, which depends on a specific meta-parameter of the model, you should be able to choose the appropriate parameter by reading the plot and explain your choice based on the bias-variance tradeoff.
        🔗
        🔗
      • Given a dataset, you should be able to generate this plot yourself in Python for any type of model covered in this class.
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗

    Subsection Subset/Feature Selection

    Required readings: Chapter Section 6.1 (9 pages)
    🔗
    • Why shouldn’t you have as many predictors in your model as possible?
      🔗
      🔗
    • What are the three basic methods that could be used to select the appropriate predictors (feature selection)?
      🔗
      🔗
    • What are the steps and procedures in the algorithm for each of these methods?
      🔗
      🔗
    • How do you implement these procedures by hand, given the training and cross-validation test errors for each combination of predictors?
      🔗
      🔗
    • What are the pros and cons of each feature selection method? When can or can’t you use them?
      🔗
      🔗
    • How do you implement the feature selection algorithms in Python?
      🔗
      🔗
    🔗
    🔗

    Subsection Regularization Methods

    Required readings: Chapter Sections 6.2.1-6.2.2 (12 pages)
    🔗
    • What is regularization? Why do we need it?
      🔗
      🔗
    • What are the two basic types of regularization methods? How are they implemented mathematically in linear regression? Why are they also called shrinkage methods?
      🔗
      🔗
    • How do you fit these two basic types of regularized linear regression models in Python?
      🔗
      🔗
    • How do you control model flexibility and the bias-variance tradeoff when using regularization?
      🔗
      🔗
    • How do you find the right amount of regularization using cross-validation? How do you do this in Python?
      🔗
      🔗
    • What additional precautions do you need to take when using regularization compared to least squares?
      🔗
      🔗
    • What are the advantages of regularization compared to least squares?
      🔗
      🔗
    • What are the advantages of regularization compared to subset selection?
      🔗
      🔗
    • What are the advantages of one shrinkage method over another? When should you choose one over the other?
      🔗
      🔗
    🔗
    🔗

    Subsection Dimensionality Reduction and Feature Engineering

    Required readings: Chapter Section 6.3 (9 pages)
    🔗
    • How do you create new variables as linear combinations of the original predictors?
      🔗
      🔗
    • Why do we need Principal Component Analysis (PCA)? What is its main purpose?
      🔗
      🔗
    • What is a principal component (PC)?
      • What does the first PC maximize? You should be able to explain this both geometrically in a plot and mathematically.
        🔗
        🔗
      • Similarly, what do the subsequent PCs maximize?
        🔗
        🔗
      🔗
      🔗
    • How do you compute the PCs in Python, given a dataset?
      • How do you project data points onto each PC? You should also be able to plot the data points in PC space.
        🔗
        🔗
      • How do you determine how much variance each PC explains?
        🔗
        🔗
      🔗
      🔗
    • Why would you want to use PCs in regression models?
      • What assumptions must hold for principal component regression (PCR) to be a good idea?
        🔗
        🔗
      • Conversely, what is a typical scenario in which using PCR would be a bad idea?
        🔗
        🔗
      🔗
      🔗
    • How do you implement PCR in Python?
      🔗
      🔗
    • How do you interpret the model coefficients when using PCR?
      🔗
      🔗
    • How do you choose the number of PCs to use in PCR?
      • Given a figure of cross-validation score as a function of the number of PCs, you should be able to choose the appropriate number and justify your choice in terms of the bias-variance tradeoff.
        🔗
        🔗
      • You should be able to generate such figures in Python.
        🔗
        🔗
      🔗
      🔗
    • What are the relationships and differences between PCR, feature selection, and the regularization methods you learned in this part of the course?
      🔗
      🔗

    Subsection Exam 2 practice problems

    Checkpoint 142.

    The figure below shows the solution to the constrained optimization problem
    \begin{equation*} \min_{\boldsymbol{\beta}} \sum_{i=1}^{n}(y_i-\hat{y}_i)^2 \quad \text{subject to} \quad \sum_{j=1}^{p}|\beta_j|\leq s, \end{equation*}
    where \(s\) corresponds to a particular value of the tuning parameter \(\lambda\text{.}\)
    🔗
    For each figure, write down the resulting model, including the constant term \(\beta_0\text{.}\)
    🔗
    Hint: Chapter 6.2.
    🔗

    Checkpoint 143.

    The \(\ell_1\) norm of the fitted coefficients using ordinary least squares multiple regression was found to be \(150\text{.}\) Use the table and figure provided to write down the expression for the model fit using LASSO regression.
    🔗
    Hint: Chapter 6.2.

    Checkpoint 145.

    This dataset corresponds to an experiment with 30 data points measuring the resistance of rubber to abrasion, using hardness and tensile strength as predictors. Hardness was measured in degrees Shore (degree S), with higher values indicating harder rubber. Abrasion loss was measured in grams per hour (g/h). Assume the data are already randomized in the order shown in the table, and answer the following questions.
    🔗
    Source: Davies, O. L., and Goldsmith, P. L. (eds.) (1972), Statistical Methods in Research and Production, 4th edition, Edinburgh: Oliver and Boyd, p. 239.
    🔗
    1. Show the full computations, including the equations used, for the mean squared error (MSE) of the first fold in 10-fold cross-validation.
      🔗
      Hint: Chapters 5.1-5.3.
      🔗
      🔗
    2. Using only the first three rows of the data and ignoring all others, show the full computations, including the equations used, for the MSE using leave-one-out cross-validation (LOOCV).
      🔗
      Hint: Chapters 5.1-5.3.
      🔗
      🔗
    3. Using only the first six rows of the data and ignoring all others, show the full computations, including the equations used, for the MSE using the validation-set approach. If you make any decisions about data selection, state them clearly.
      🔗
      Hint: Chapters 5.1-5.3
