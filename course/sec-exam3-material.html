    7.1: Polynomial regression
    🔗
    7.2: Step functions (regression and classification)
    🔗
    7.3: Basis functions
    🔗

    Objectives: Covered in this class

    • Why do people want to use polynomial regression rather than simple linear regression?
      🔗
    • How do you fit polynomial regression models?
      🔗
    • Why do people want to use step functions rather than simple linear regression?
      🔗
    • How do you fit step function models?
      🔗
    • What do polynomial regression and step functions have in common?
      🔗
    • What are the differences between polynomial regression and step functions?
      🔗
    • How do you fit step function models for classification problems?
      🔗
    • You should also be able to implement them in Python.
      🔗
    • What is the purpose of using basis functions?
      🔗
    • You should be able to articulate what the basis functions \(b_i\) are for polynomial regression and step functions.
      🔗

    Polynomial regression.

    Replace the linear model
    🔗
    \begin{equation*} y_i = \beta_0 + \beta_1 x_i + \varepsilon_i \end{equation*}
    🔗
    with
    🔗
    \begin{equation*} y_i = \beta_0 + \beta_1 x_i + \beta_2 x_i^2 + \cdots + \beta_d x_i^d + \varepsilon_i \end{equation*}
    🔗
    • Can learn with linear models by passing in predictors \(x_i^\ell\text{.}\)
      🔗
      🔗
    • Tend not to go higher than degree 3 or 4 because this can make the model overly flexible.
      🔗
      🔗
    • Resulting model is global.
      • Can miss important localized information.
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗

    Example: Wage Data.

    \begin{equation*} \texttt{wage} = \beta_0 + \beta_1\texttt{age} + \beta_2\texttt{age}^2 + \cdots + \beta_p\texttt{age}^p + \varepsilon. \end{equation*}
    🔗
    Using OLS to fit a polynomial model: Treat higher powers as separate predictors.
    • Make a matrix of predictors \(X\) with columns \(X^0, X^1, X^2, \ldots, X^p\text{.}\)
      🔗
      \(X_0\) \(X_1\) \(X_1^2\) \(\ldots\) \(X_1^p\)
      1
      2
      \(\vdots\)
      \(n\)
      🔗
    • Then use linear regression to learn the coefficients.
      🔗
      🔗
    🔗
    The code learned:
    \begin{align*} \widehat{\texttt{wage}} \amp= -184.1542 + 21.24552\,\texttt{age}\\ \amp- 0.56386\,\texttt{age}^2 + 0.00681\,\texttt{age}^3\\ \amp- 3\times 10^{-5}\,\texttt{age}^4 \end{align*}
    🔗
    
    Scatter plot of the Wage data depicting wage versus age for men in the Mid-Atlantic region of the United States. The solid blue curve is a degree-4 polynomial of wage (in thousands of dollars) as a function of age, fit by least squares. The dashed curves indicate an estimated 95% confidence interval
    🔗
    • The dark line is a degree 4 polynomial.
      🔗
      🔗
    • There is an estimated variance for each coefficient.
      • Assume the fitted model is
        \begin{equation*} \hat f(x_0) = \hat\beta_0 + \hat\beta_1 x_0 + \cdots + \hat\beta_d x_0^d. \end{equation*}
        🔗
        🔗
      • Use this model to estimate the pointwise variance \(\operatorname{Var}(\hat f(x_0))\text{.}\)
        🔗
        🔗
      • Draw two standard deviations away from the fitted line to obtain an approximate 95% confidence interval.
        🔗
      🔗
      🔗
    🔗
    • We notice that the data contains two groups: high earners, and low earners.
      🔗
      🔗
    • Most of the data is low earners (about 79 high earners only out of 3000 data points).
      🔗
      🔗
    • A global model (such as polynomial regression) will impose global structure on the data.
      🔗
      🔗
    • Step functions allow learning localized models.
      🔗
      🔗
    🔗
    🔗

    Step functions.

    More generally:
    \begin{align*} C_0(X) \amp = I(X \lt c_1),\\ C_1(X) \amp = I(c_1 \le X \lt c_2),\\ C_2(X) \amp = I(c_2 \le X \lt c_3),\\ \amp \vdots\\ C_{K-1}(X) \amp = I(c_{K-1} \le X \lt c_K),\\ C_K(X) \amp = I(c_K \le X), \end{align*}
    🔗
    • Choose values for the knots \(c_1,\ldots,c_K\text{.}\)
      🔗
      🔗
    • \(I(\cdot)\) is an indicator function. It returns 1 if its argument is true, and 0 otherwise.
      🔗
      🔗
    • Use indicator functions to break up the range of \(X\) into bins, then fit a new constant in each bin.
      🔗
      🔗
    • The \(C_j\) terms are sometimes also called dummy variables.
      🔗
      🔗
    • Note that \(\sum_j C_j(X)=1\) because \(X\) belongs to exactly one interval.
      🔗
      🔗
    🔗
    • Step functions allow models to be learned without imposing a global structure.
      🔗
      🔗
    • They are very popular in biostatistics and epidemiology. 5-year age groups are often used to define the bins.
      🔗
      🔗
    🔗
    🔗

    Step function: Learned model.

    \begin{equation*} y_i = \beta_0 + \beta_1 C_1(x_i) + \beta_2 C_2(x_i) + \cdots + \beta_K C_K(x_i) + \varepsilon_i \end{equation*}
    🔗
    • Note that we do not learn a coefficient for \(C_0\text{.}\) As with qualitative predictors, its value can be determined from the other coefficients.
      🔗
      🔗
    • If \(X \lt c_1\text{,}\) all predictors are zero, so \(\beta_0\) is the mean value of \(Y\) for \(X \lt c_1\text{.}\)
      🔗
      🔗
    • For \(X\in[c_j,c_{j+1})\text{,}\) the response is \(\beta_0+\beta_j\text{.}\) Thus, \(\beta_j\) is the average change in response for \(X\) in that interval relative to \(X \lt c_1\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Checkpoint 111 Coffee shop sales step regression.

    Suppose we want to predict the number of coffees sold per hour (\(Y\)) at a campus coffee shop based on the time of day (\(X\text{,}\) measured in hours since opening from 8:00 AM to 4:00 PM, where \(X \in [0,8]\)).
    🔗
    A sample dataset of 20 hourly observations is provided in Table 112.
    🔗

    (a)

    Fit an intercept-only model (0 cutpoints). Is this a good model?
    🔗
    Solution.
    If we fit an intercept-only model, \(F(X) = \beta_0\text{,}\) our best prediction is the global average of all observations:
    \begin{equation*} \beta_0 \approx 79.55 \text{ coffees/hour} \end{equation*}
    This model underfits significantly, completely missing the morning and afternoon fluctuations.
    🔗
    🔗
    🔗

    (b)

    Introduce a single split at noon to segment the data into Morning (\(X \lt 4\)) and Afternoon (\(X \ge 4\)). Fit the resulting model.
    🔗
    Solution.
    The resulting model with one cutpoint at noon is
    \begin{equation*} F(X) = \beta_0 + \beta_1 I(X \ge 4). \end{equation*}
    Averaging the subsets yields:
    • Morning Step (Observations 1-8): \(\beta_0 = 63.5\)
      🔗
      🔗
    • Afternoon Step (Observations 9-20): \(\beta_0 + \beta_1 = 78.83 \implies \beta_1 = 15.33\)
      🔗
      🔗
    🔗
    🔗
    🔗

    (c)

    Can you think of a partition that can better capture the peak hours’ rush? There is not a unique solution to this part.
    🔗
    Solution.
    We can use 3 cutpoints at \(c_1 = 3.0, c_2 = 5.0, c_3 = 6.0\text{.}\) We fit the model
    \begin{equation*} F(X) = \beta_0 + \beta_1 C_1(X) + \beta_2 C_2(X) + \beta_3 C_3(X) \end{equation*}
    where:
    \begin{align*} C_1(X) \amp = I(3.0 \le X \lt 5.0)\\ C_2(X) \amp = I(5.0 \le X \lt 6.0)\\ C_3(X) \amp = I(6.0 \le X) \end{align*}
    Calculating the averages within each interval yields:
    \begin{equation*} F(X) = \begin{cases} 50.0 \amp \text{if } X \lt 3.0 \\ 121.0 \amp \text{if } 3.0 \le X \lt 5.0 \\ 40.0 \amp \text{if } 5.0 \le X \lt 6.0 \\ 80.71 \amp \text{if } X \ge 6.0 \end{cases} \end{equation*}
    This refinement level seems to capture the underlying demand wave of the shop without overfitting.
    🔗
    🔗
    🔗
    🔗

    Classification versions.

    Remember logistic regression?
    🔗
    Logistic regression:
    \begin{equation*} p(X) = \frac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}} \end{equation*}
    🔗
    Multiple features (Multiple logistic regression):
    🔗
    \begin{equation*} p(X) = \frac{e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}} {1+e^{\beta_0+\beta_1X_1+\cdots+\beta_pX_p}} \end{equation*}
    🔗
    🔗

    Classification version: Polynomial regression.

    \begin{equation*} \Pr(y_i>250 \mid x_i) = \frac{\exp(\beta_0+\beta_1x_i+\cdots+\beta_dx_i^d)} {1+\exp(\beta_0+\beta_1x_i+\cdots+\beta_dx_i^d)} \end{equation*}
    🔗
    • The previous figure shows a distinct subcluster of high earners making more than $250K.
      🔗
      🔗
    • Build a logistic regression model as above.
      🔗
      🔗
    • The 95% confidence interval gets very wide on the right side.
      🔗
      🔗
    • The large sample size, \(n=3{,}000\text{,}\) but small number of high earners (79) leads to high coefficient variance and wide confidence intervals.
      🔗
      🔗
    🔗
    🔗

    Classification version: Step functions.

    \begin{equation*} \Pr(y_i>250 \mid x_i) = \frac{\exp(\beta_0+\beta_1C_1(x_i)+\beta_2C_2(x_i)+\cdots+\beta_KC_K(x_i))} {1+\exp(\beta_0+\beta_1C_1(x_i)+\beta_2C_2(x_i)+\cdots+\beta_KC_K(x_i))} \end{equation*}
    🔗
    • Again, the model learns that middle region.
      🔗
      🔗
    • The confidence interval is still large on the right, likely because there is less data there.
      🔗
      🔗
    🔗
    🔗

    Basis Functions Setup.

    Polynomial and piecewise-constant regression models are special cases of a basis function approach.
    🔗
    \begin{equation*} y_i = \beta_0 + \beta_1b_1(x_i) + \beta_2b_2(x_i) + \cdots + \beta_Kb_K(x_i) + \epsilon_i \end{equation*}
    🔗
    • Pick a collection of basis functions \(b_1(X),\cdots,b_K(X)\text{.}\)
      🔗
      🔗
    • Use least squares to figure out the coefficients.
      🔗
      🔗
    • Explain the \(b_i\) for polynomial and stepwise functions.
      🔗
      🔗
    • In contrast to dimension-reduction methods, here we want to add dimensions.
      🔗
      🔗
    🔗
    • There are lots of possible options for basis functions.
      • Examples include wavelets and Fourier series.
        🔗
        🔗
      • Another is regression splines, which we will learn in this class.
        🔗
        🔗

    7.4 Regression Splines
    🔗

    Objectives: Covered in this class

    • You should be able to articulate what the basis functions \(b_i\) are for cubic splines.
      🔗
    • How do you define cubic splines mathematically?
      • You should be able to write down the equations for the model between knots.
        🔗
      • And the equations for constraints at the knots.
        🔗
      🔗
      🔗
    • How to calculate the cubic spline coefficients by hand by applying the above mathematical definitions?
      🔗
    🔗

    Regression Splines.

    Piecewise polynomials
    🔗
    Fit a polynomial regression:
    🔗
    \begin{equation*} y_i = \beta_0 + \beta_1x_i + \beta_2x_i^2 + \cdots + \beta_dx_i^d + \epsilon_i \end{equation*}
    🔗
    Let the \(\beta_i\) values be different at different locations in the range.
    🔗
    • Points where the coefficients change are called “knots.”
      🔗
      🔗
    • A piecewise cubic with no knots is just a standard cubic polynomial.
      🔗
      🔗
    • More knots give a more flexible polynomial.
      🔗
      🔗
    • The piecewise-constant model from the previous section is the degree-zero version of this.
      🔗
      🔗
    🔗
    🔗

    Example of piecewise polynomial.

    Example:
    \begin{equation*} y_i = \begin{cases} \beta_{01} + \beta_{11}x_i + \beta_{21}x_i^2 + \beta_{31}x_i^3 + \epsilon_i \amp \text{if } x_i < c \\ \beta_{02} + \beta_{12}x_i + \beta_{22}x_i^2 + \beta_{32}x_i^3 + \epsilon_i \amp \text{if } x_i \geq c \end{cases} \end{equation*}
    🔗
    • The model uses 8 degrees of freedom.
      🔗
      🔗
    • The problem is that the function is discontinuous.
      🔗
      🔗
    🔗
    🔗

    The fix.

    • Fit a piecewise polynomial.
      🔗
      🔗
    • Require continuity at the knots.
      🔗
      🔗
    🔗
    The curve looks better, but the pointy join is odd.
    🔗
    🔗

    The better fix: Cubic splines.

    • Fit a piecewise polynomial.
      🔗
      🔗
    • Require continuity at the knots.
      🔗
      🔗
    • Require the first and second derivatives to be continuous at the knots.
      🔗
      🔗
    🔗
    • Now we have smooth joins. This is called a “cubic spline.”
      🔗
      🔗
    • The model has 8 original degrees of freedom, plus three constraints (continuity, first-derivative continuity, and second-derivative continuity), leaving 5 degrees of freedom.
      🔗
      🔗
    • A cubic spline with \(K\) knots uses \(3+K\) degrees of freedom.
      🔗
      🔗
    🔗
    🔗

    Example 113 Computing coefficients of a piecewise cubic polynomial.

    We have the following piecewise cubic polynomial:
    🔗
    \begin{equation*} f(x) = \begin{cases} 2+x+x^2+0.1x^3 & x \leq 1 \\ b_0+b_1x+b_2x^2-x^3 & x > 1 \end{cases} \end{equation*}
    🔗
    What are the values of \(b_0\), \(b_1\), and \(b_2\) that make this a cubic spline?
    🔗
    Hint.
    A cubic spline must be continuous and have continuous first and second derivatives at the breakpoint \(x=1\). Set the function values, first derivatives, and second derivatives equal at \(x=1\) to obtain a system of three equations.
    🔗
    🔗
    Solution.
    First, impose continuity at \(x=1\text{:}\)
    🔗
    \begin{equation*} 2+1+1+0.1=b_0+b_1+b_2-1, \end{equation*}
    🔗
    which gives
    🔗
    \begin{equation*} b_0+b_1+b_2=5.1. \end{equation*}
    🔗
    Next, impose continuity of the first derivative. Matching at \(x=1\) gives
    🔗
    \begin{equation*} 3.3=b_1+2b_2-3, \end{equation*}
    🔗
    or
    🔗
    \begin{equation*} b_1+2b_2=6.3. \end{equation*}
    🔗
    Finally, impose continuity of the second derivative:
    🔗
    \begin{equation*} 2.6=2b_2-6, \end{equation*}
    🔗
    so
    🔗
    \begin{equation*} b_2=4.3. \end{equation*}
    🔗
    Substituting back, we obtain
    🔗
    \begin{equation*} b_1=-2.3,\qquad b_0=3.1. \end{equation*}
    🔗
    Therefore, the coefficients are
    🔗
    \begin{equation*} b_0=3.1,\quad b_1=-2.3,\quad b_2=4.3. \end{equation*}

    Building up to cubic splines.

    A piecewise cubic regression can be discontinuous at a knot. Requiring continuity removes the jump, but the fit may still have a pointy join. A cubic spline also requires the first and second derivatives to be continuous at each knot, producing a smooth join.
    🔗
    \begin{equation*} f(x)=\begin{cases}\beta_0^1+\beta_1^1x+\beta_2^1x^2+\beta_3^1x^3 & x<c\\\beta_0^2+\beta_1^2x+\beta_2^2x^2+\beta_3^2x^3 & x>c\end{cases} \end{equation*}
    🔗
    With one knot, there are initially eight coefficients. Continuity of the function and its first two derivatives gives three constraints, leaving five degrees of freedom. A cubic spline with \(K\) knots uses \(4+K\) degrees of freedom.
    🔗
    🔗

    Basis representations.

    • Choose basis functions \(b_i\) to represent a cubic spline with \(K\) knots:
      🔗
      \begin{equation*} y_i=\beta_0+\beta_1b_1(x_i)+\beta_2b_2(x_i)+\cdots+\beta_{K+3}b_{K+3}(x_i)+\epsilon_i \end{equation*}
      🔗
      🔗
    • There is no unique basis representation. The book uses a different basis; this material follows scikit-learn’s approach.
      🔗
      🔗
    • The truncated power basis function is \(h(x,z)=(x-z)^3_+\text{,}\) defined to be \((x-z)^3\) when \(x>z\) and zero otherwise. The book writes the knot as \(\xi\text{;}\) here it is written as \(z\text{.}\)
      🔗
      🔗
    • For knots \(z_1,\ldots,z_K\text{,}\) the book’s basis consists of \(X\text{,}\) \(X^2\text{,}\) \(X^3\text{,}\) and \(h(X,z_1),\ldots,h(X,z_K)\text{.}\) Adding \(h(X,z_i)\) introduces a discontinuity in the third derivative at \(z_i\text{.}\)
      🔗
      \begin{equation*} f(X)=\beta_0+\beta_1X+\beta_2X^2+\beta_3X^3+\beta_4h(X,z_1)+\beta_5h(X,z_2)+\cdots+\beta_{K+3}h(X,z_K) \end{equation*}
      🔗
      🔗
    • These \(3+K\) basis functions and the intercept give \(K+4\) coefficients, matching the degrees of freedom from the piecewise-polynomial construction.
      🔗
      🔗
    • A B-spline basis instead combines functions that are continuous and differentiable everywhere.
      🔗
      🔗
    🔗

    Notes on cubic splines. Natural cubic splines..

    • A natural spline is a regression spline with boundary constraints that require the function to be linear at the boundaries.
      🔗
      🔗
    • The natural boundary conditions eliminate two additional degrees of freedom by requiring zero curvature at the endpoints:
      \begin{equation*} f''(X_{\text{left}})=0,\qquad f''(X_{\text{right}})=0. \end{equation*}
      🔗
      🔗
    • Cubic splines are often useful because the eye may not detect their remaining discontinuities, though variance can still be high near the outer range of the predictors.

      🔗

    How do we actually get the tree? Two steps.

    1. We divide the predictor space -- that is, the set of possible values for \(X_1, X_2, \ldots, X_p\) -- into \(J\) distinct and non-overlapping regions, \(R_1, R_2, \ldots, R_J\text{.}\)
      🔗
      🔗
    2. For every observation that falls into the region \(R_j\text{,}\) we make the same prediction: the mean of the response values for the training observations in \(R_j\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Step 1: How do we decide on \(R_j\)s?

    Goal:
    🔗
    Find boxes \(R_1,\ldots,R_J\) that minimize
    🔗
    \begin{equation*} \sum_{j=1}^J \sum_{i \in R_j} (y_i-\hat y_{R_j})^2 \end{equation*}
    🔗
    \(\hat y_{R_j}\) = mean response for training observations in the \(j\)th box.
    🔗
    • Cost is just RSS.
      🔗
      🔗
    • Can’t actually check every possible partition.
      🔗
      🔗
    • Instead, use a top-down greedy approach called \(\text{Recursive binary splitting}\text{.}\)
      🔗
      🔗
    • Begins at the top of the tree with all data points.
      🔗
      🔗
    • Uses the best split at every step.
      🔗
      🔗
    🔗
    🔗

    Recursive Binary Splitting.

    One split:
    🔗
    • Pick \(X_j\) and cutpoint \(s\text{.}\)
      🔗
      🔗
    • Choose them so that splitting into \(\{X \mid X_j < s\}\) and \(\{X \mid X_j \geq s\}\) results in the largest possible reduction in RSS.
      🔗
      🔗
    🔗
    • Note here we look at all combinations of \(X_j\) and \(s\) for each split of the tree.
      🔗
      🔗
    🔗
    \begin{equation*} \begin{aligned} R_1(j,s) &= \{X \mid X_j < s\}\\ R_2(j,s) &= \{X \mid X_j \geq s\} \end{aligned} \end{equation*}
    🔗
    \begin{equation*} \begin{aligned} &\sum_{i \mid x_i \in R_1(j,s)}(y_i - \hat y_{R_1})^2\\ &+\sum_{i \mid x_i \in R_2(j,s)}(y_i - \hat y_{R_2})^2 \end{aligned} \end{equation*}
    🔗
    🔗

    Rinse and repeat.

    • Do this repeatedly.
      🔗
      🔗
    • Each time, we can split one of the previously identified regions.
      🔗
      🔗
    • Keep going until some stopping criterion is reached. For example, continue until each region has at most 5 observations.
      🔗
      🔗
    🔗
    🔗

    Decision trees for classification: Basic idea.

    
    Example decision tree for classificaiton using the Heart dataset.
    🔗
    • Can’t use RSS; need an error rate.
      🔗
      🔗
    • Define \(\hat p_{mk}\) = proportion of training observations in \(R_m\) from the \(k\)th class. Then the classification error for region \(R_m\) is given by:
      \begin{align*} E \amp= 1-\max_k(\hat p_{mk})\\ \amp= \frac{\text{no.~of minority class observations in } R_m}{\text{total observations in } R_m} \end{align*}
      🔗
      • Fraction of training observations not in the most common class for that region.
        🔗
        🔗
      🔗
      🔗
    🔗
    • The split error for classification is the weighted average of the errors for the left and right nodes, where the weights are the proportions of observations in each node. The formula for the error \(E_s\) is given below for split \(s\text{.}\)
      \begin{equation*} \text{E}_s = \frac{N_{\text{left}}}{N} \times E_{\text{left}} + \frac{N_{\text{right}}}{N} \times E_{\text{right}} \end{equation*}
      where \(N\) is the number of points in the parent node, \(N_{\text{left}}\) and \(N_{\text{right}}\) are the number of points in the left and right child nodes, respectively. \(E_{\text{left}}\) and \(E_{\text{right}}\) are the classification errors for the left and right child nodes, respectively.
      🔗
      🔗
    • In practice, the splits are decided based on Gini index or cross-entropy, but we will not discuss those in our class.
      • We will use the misclassification error rate for by-hand computation of the splits in our class, which is easier to understand and compute.
        🔗
        🔗
      🔗
      🔗
    • Gini index, cross-entropy, or misclassification error rate can be used for pruning; however, the prediction accuracy is the goal, then classification error rate is preferable for pruning.

      🔗

    Bagging: Use ensemble of trees to reduce variance.

    Want to do (but can’t):
    🔗
    Build separate models from independent training sets, and average resulting predictions:
    🔗
    • \(\hat f^1(x), \cdots, \hat f^B(x)\) for \(B\) separate training sets.
      🔗
      🔗
    • Return the average:
      🔗
      🔗
    🔗
    \begin{equation*} \hat f_{\text{avg}}(x) = \frac{1}{B} \sum_{b=1}^B \hat f^b(x) \end{equation*}
    🔗
    • Decreases variance, but is not practical.
      🔗
      🔗
    🔗
    Bootstrap modification:
    🔗
    • Work with a fixed data set.
      🔗
      🔗
    • Take \(B\) samples from this data set (with replacement).
      🔗
      🔗
    • Train the method on the \(b\)th sample to get \(\hat f^{*b}(x)\text{.}\)
      🔗
      🔗
    • Return the average of predictions (regression):
      🔗
      🔗
    🔗
    \begin{equation*} \hat f_{\text{bag}}(x) = \frac{1}{B} \sum_{b=1}^B \hat f^{*b}(x) \end{equation*}
    🔗
    Or use majority vote (classification).
    🔗
    🔗

      🔗

      🔗
      🔗

      🔗

    Estimating the test error: Out of Bag (OOB) error.

    • On average, a bootstrap sample uses about 2/3 of the data.
      🔗
      🔗
    • The remaining observations not used are called out-of-bag (OOB) observations.
      🔗
      🔗
    • For each observation, run it through all the trees for which it was not used in training.
      🔗
      🔗
    • Return the average (or majority vote) of those predictions as the test prediction. This relies on the law of large numbers.
      🔗
      🔗
    • For B sufficiently large, OOB error is equivalent to leave-one-out cross-validation error.
      🔗
      🔗
    • OOB error is a good estimate of test error, and is more computationally efficient that cross-validation especially for large datasets.

    Random forests: The idea.

    Goal: decorrelate the bagged trees.
    🔗
    • If there is a strong predictor, the first split of most trees will be the same.
      🔗
      🔗
    • Most or all trees will be highly correlated.
      🔗
      🔗
    • Averaging highly correlated quantities does not decrease variance as much as averaging uncorrelated quantities.
      🔗
      🔗
    🔗
    The random forest fix:
    🔗
    • Each time a split is considered, use only a random subset of \(m\) of the predictors.
      🔗
      🔗
    • Take a fresh sample of predictors at every split.
      🔗
      🔗
    • Typically for classification, \(m \approx \sqrt{p}\text{.}\)
      🔗
      🔗
    • For regression, \(m \approx p/3\) is a common starting point (often tuned further using the OOB error).
      🔗
      🔗
    • On average, \((p-m)/p\) of the splits will not consider the strong predictor.
      🔗
      🔗
    • \(m=p\) gives back bagging.
      🔗
      🔗
    🔗
    🔗

    What is a hyperplane?

    • In \(p\)-dimensional space, a hyperplane is a flat affine subspace of dimension \(p-1\text{.}\)
      🔗
      🔗
    • Affine means it does not have to pass through the origin.
      🔗
      🔗
    🔗
    🔗

    Mathematical definition of a hyperplane.

    \begin{equation*} \beta_0+\beta_1X_1+\beta_2X_2+\cdots+\beta_pX_p=0 \end{equation*}
    🔗
    • Being on the hyperplane means having a point \(X=(X_1,X_2,\cdots,X_p)^T\) satisfying this equation.
      🔗
      🔗
    • The vector \(\beta=(\beta_1,\beta_2,\cdots,\beta_p)^T\) is the normal vector to the hyperplane.
      • If \(\boldsymbol{\beta}=(\beta_1,\beta_2,\cdots,\beta_p)^T\) is normalized such that \(\sum_{j=1}^p \beta_{j}^2 = 1\text{,}\) then \(\boldsymbol{\beta}\) represents the unit normal vector to the hyperplane.
        🔗
        🔗
      • The signed perpendicular distance from a point \(\mathbf{x}_i=(x_{i1},x_{i2},\cdots,x_{ip})^T\) to the hyperplane is given by
        \begin{equation*} \frac{\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip}}{\sqrt{\sum_{j=1}^p \beta_{j}^2}}=\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip} \end{equation*}
        🔗
        🔗
      🔗
      🔗
    🔗

    Aside: Dot product.

    The quantity
    \begin{equation*} \beta_{0} + \beta_{1} x_{1} + \beta_{2} x_{2} + \ldots + \beta_{N} x_{N} \end{equation*}
    🔗
    Is the same as
    \begin{equation*} \begin{bmatrix} \beta_0 \amp \beta_1 \amp \beta_2 \amp \ldots \amp \beta_N \end{bmatrix}\begin{bmatrix}1\\x_1\\x_2\\\vdots\\x_N\end{bmatrix} \end{equation*}
    🔗
    Is the same as
    \begin{equation*} \begin{bmatrix} \beta_0 \\ \beta_1 \\\beta_2 \\ \vdots \\ \beta_N \end{bmatrix} \cdot \begin{bmatrix}1\\x_1\\x_2\\\vdots\\x_N\end{bmatrix} \end{equation*}
    🔗
    Is the same as
    \begin{equation*} \beta_{0} + \boldsymbol{\beta}^{T} \mathbf{x} \end{equation*}
    🔗
    where \(\mathbf{\beta}=\begin{bmatrix}\beta_{0} \\ \beta_{1} \\\beta_{2} \\ \vdots \\ \beta_{N}\end{bmatrix}\) and \(\mathbf{x}= \begin{bmatrix}1\\x_{1}\\x_{2}\\\vdots\\x_{N}\end{bmatrix}\)
    🔗
    🔗

    🔗

    Objectives

    • What is the difference between the Support Vector Classifier and the Maximal Margin Classifier?

        🔗

      • Given a graph of a Support Vector Classifier and some data points, you should be able to derive the values of different parameters in the mathematical formulation (e.g., \(M\text{,}\) \(\epsilon_i\)).
        🔗

      🔗

    Support Vector Classifier (SVC): Basic idea.

    • Be okay with having a classifier that isn’t quite perfect.
      🔗
      🔗
    • Aim for greater robustness to individual observations.
      🔗
      🔗
    • Better classification of most of the training observations.
      🔗
      🔗
    • The result is a support vector classifier.
      🔗
      🔗
    • Also called a soft margin classifier.
      🔗
      🔗
    🔗
    🔗

    Soft margin.

    • Some points on the wrong side of the margin.
      🔗
      🔗
    🔗
    • Some points on the wrong side of the hyperplane (misclassified).
      🔗
      🔗
    🔗
    🔗

    Mathematical formulation of SVC.

    \begin{align*} \amp \underset{\beta_0, \beta_1, \dots, \beta_p, \epsilon_1, \dots, \epsilon_n, M}{\text{maximize}} \quad M\\ \amp \text{subject to} \quad \sum_{j=1}^{p} \beta_j^2 = 1,\\ \amp y_i(\beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \cdots + \beta_p x_{ip}) \geq M(1 - \epsilon_i),\\ \amp \epsilon_i \geq 0, \quad \sum_{i=1}^{n} \epsilon_i \leq C, \end{align*}
    🔗
    • \(C\) is a nonnegative tuning parameter
      🔗
      🔗
    • \(M\) is the width of the margin
      🔗
      🔗
    • \(\epsilon_1, \dots, \epsilon_n\) are slack variables:
      • \(0 \lt \epsilon_i \gt 1\text{:}\) Allow the ith observation to be within the margin \(M\text{.}\)
        🔗
        🔗
      • \(\epsilon_i \gt 1\text{:}\) Allow misclassification.
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗

    What is \(\epsilon\text{?}\)

    • If \(\epsilon_i=0\text{,}\) then the observation is on the correct side of the margin.
      🔗
      🔗
    • If \(\epsilon_i>0\text{,}\) then the observation is on the wrong side of the margin (violated margin).
      🔗
      🔗
    • If \(\epsilon_i>1\text{,}\) then the observation is on the wrong side of the hyperplane.
      🔗
      🔗
    🔗
    🔗

    Example 141 Finding the range of \(\epsilon_i\).

    Fix the margin \(M=\sqrt{2}\text{,}\) and recall that
    \begin{equation*} y_i(\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip}) \geq M(1-\epsilon_i) \end{equation*}
    🔗
    Choose the correct \(\epsilon_i\) range for each of the following points.
    🔗

    (a)

    Which of the following is true for \(\epsilon_A\text{?}\)
    🔗
    • \(\epsilon_A=0\)
    • Correct! Point A is on the correct side of the classifier, outside of the margin \(M\text{,}\) so \(\epsilon_A=0\text{.}\)
    • \(0 \lt \epsilon_A \lt 0\)
    • \(\epsilon_A \gt 0\)
    🔗

    (b)

    Which of the following is true for \(\epsilon_B\text{?}\)
    🔗
    • \(\epsilon_B=0\)
    • \(0 \lt \epsilon_B \lt 0\)
    • Correct! Point B is on the correct side of the classifier, but within the margin \(M\text{,}\) so \(0 \lt \epsilon_B \lt 1\text{.}\)
    • \(\epsilon_B \gt 0\)
    🔗

    (c)

    Which of the following is true for \(\epsilon_C\text{?}\)
    🔗
    • \(\epsilon_C=0\)
    • \(0 \lt \epsilon_C \lt 0\)
    • \(\epsilon_C \gt 0\)
    • Correct! Point C is on the wrong side of the classifier, so \(\epsilon_C \gt 1\text{.}\)
    🔗
    🔗

    \begin{equation*} y_i(\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip}) \geq M(1-\epsilon_i) \end{equation*}
    🔗
    Fill in the table so that the inequality is satisfied.
    🔗

    Total \(\epsilon\) is 5.
    🔗

    What is \(C\text{?}\)

    \begin{gather*} \underset{\beta_0,\beta_1,\ldots,\beta_p,\epsilon_1,\ldots,\epsilon_n,M}{\text{maximize}} \quad M\\ \text{subject to}\quad \sum_{j=1}^{p}\beta_j^2=1\\ y_i(\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip}) \geq M(1-\epsilon_i)\\ \epsilon_i\geq 0,\qquad \sum_{i=1}^{n}\epsilon_i\leq C \end{gather*}
    🔗
    • \(C\) is nonnegative tuning parameter.
      🔗
      🔗
    • Bounds the sum of the \(\epsilon_i\text{,}\) so it controls the number and severity of margin violations (the budget).
      🔗
      🔗
    • \(C=0\) means no violations are allowed.
      🔗
      🔗
    • \(C > 0\) means the total amount of margin violation is bounded by \(C\text{;}\) it does not necessarily limit the number of observations on the wrong side of the hyperplane to \(C\text{.}\)
      🔗
      🔗
    • In the previous example, the total of the \(\epsilon_i\) was 5, so the hyperplane satisfies the constraint for \(C\geq 5\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Examples varying \(C\).

    Increasing \(C\) \(\longrightarrow\)
    🔗
    • As \(C\) increases, the margin becomes wider, so more points can violate the margin/hyperplane.
      🔗
      🔗
    • \(C\) controls the bias-variance trade-off:
      • Small \(C\text{:}\) less flexibility, lower bias, higher variance.
        🔗
        🔗
      • Large \(C\text{:}\) more flexibility, higher bias, lower variance.
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗

    What affects the hyperplane?

    • Only observations on the margin or violating the margin affect the hyperplane.
      • These observations are called support vectors.
        🔗
        🔗
      • So the support vector includes points within the margin and misclassified points.
        🔗
        🔗
      • Contrast this with MMC, where the support vector is entirely composed of observations strictly on the margin.
        🔗
        🔗
      🔗
      🔗
    • Changing the positions of non-support vector points does not affect the hyperplane.
      🔗
      🔗
    🔗
    🔗

    TL;DR.

    Maximal Margin Classifier
    🔗
    \begin{align*} \amp \underset{\beta_0, \beta_1, \dots, \beta_p, M}{\text{maximize}} M\\ \amp \text{subject to } \sum_{j=1}^{p} \beta_j^2 = 1,\\ \amp y_i(\beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + \dots + \beta_p x_{ip}) \ge M\\ \quad \forall i = 1, \dots, n \end{align*}
    🔗
    Support Vector Classifier
    🔗
    \begin{gather*} \underset{\beta_0,\beta_1,\ldots,\beta_p,\epsilon_1,\ldots,\epsilon_n,M}{\text{maximize}} \quad M\\ \text{subject to}\quad \sum_{j=1}^{p}\beta_j^2=1\\ y_i(\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\cdots+\beta_px_{ip}) \geq M(1-\epsilon_i)\\ \epsilon_i\geq 0,\qquad \sum_{i=1}^{n}\epsilon_i\leq C \end{gather*}
    🔗
    🔗
