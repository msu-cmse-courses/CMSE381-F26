Data 144 Polynomial Toy Data Set.

A data file with 100 samples from the function
\begin{equation*} f(x)=(x+2)(x-2)(x+6)*x+20. \end{equation*}
The points are randomly sampled from the interval \([-6,3]\) from a uniform distribution, and noise sampled from a normal distribution is added to the output.
🔗
The data is arranged into a data frame called toy_data with two columns, x and y, where x is the input and y is the output.
x
🔗
The \(x\) value of the data point.
🔗
y
🔗
The \(y\) value of the data point.
🔗
🔗
This data is 100% simulated, and does not correspond to any real experiments.
🔗
The code used to generate this data is below.
🔗
# Set the random seed for reproducibility
np.random.seed(42)

# Define the polynomial
f = lambda x: (x+2)*(x-2)*(x+6)*x+20

# Generate data 
x_data = np.random.uniform(-6, 3, 100)
y_data = f(x_data) + np.random.normal(0, 10, size=x_data.shape)

# Generate data for plotting 
x_plot = np.linspace(-6, 3, 100)
y_plot = f(x_plot)

# Create a DataFrame to store the data
toy_data = pd.DataFrame({'x': x_data, 'y': y_data})

plt.plot(x_data,y_data, 'o', label = 'f(x) + noise')
plt.plot(x_plot, y_plot, 'k', label = 'f(x)')
plt.legend()
plt.title('Toy data: Basis functions')
