Data 211 Clustering-ToyData2 Data Set.

A data file containing 76 observations, each with two numerical predictors. This data set was randomly generated for use in the hierarchical clustering module.
🔗
The data consist of four randomly generated groups. Two groups are centered at the same location, creating overlapping clusters:
  • Cluster 1: 20 observations centered at \((0,0)\text{,}\) with standard deviation \(1\text{.}\)
    🔗
    🔗
  • Cluster 1b: 20 observations centered at \((0,0)\text{,}\) with standard deviation \(0.5\text{.}\)
    🔗
    🔗
  • Cluster 2: 15 observations centered at \((4,1)\text{,}\) with standard deviation \(0.7\text{.}\)
    🔗
    🔗
  • Cluster 3: 21 observations centered at \((1,3)\text{,}\) with standard deviation \(0.5\text{.}\)
    🔗
    🔗
🔗
The observations are concatenated and randomly shuffled before being saved. The original group memberships are therefore not explicitly identified in the resulting data file.
🔗
The code used to generate the data is below.
🔗
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(1)

n1 = 20
X1 = np.random.normal((0, 0), 1, (n1, 2))

n1b = 20
X1b = np.random.normal((0, 0), 0.5, (n1b, 2))

n2 = 15
X2 = np.random.normal((4, 1), 0.7, (n2, 2))

n3 = 21
X3 = np.random.normal((1, 3), 0.5, (n3, 2))

for A in [X1, X2, X3, X1b]:
    plt.scatter(A[:, 0], A[:, 1])

X = np.concatenate([X1, X2, X3, X1b], axis=0)
np.random.shuffle(X)
