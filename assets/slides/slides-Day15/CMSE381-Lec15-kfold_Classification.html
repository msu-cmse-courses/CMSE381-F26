Definition of k-fold CV

  • Randomly split data into k-groups (folds)
  • Approximately equal sized. For the sake of notation, say each set has ℓ points
  • Remove ith fold Ui and reserve for testing.
  • Train the model on remaining points
  • Calculate MSEi = 1 ℓ ∑ ⁡ (xj,yj)∈Ui (yj −ŷj)2
  • Rinse and repeat
Return
CV(k) = 1 k∑ i=1kMSE i

CV for Classification
Setup: LOOCV

  • Remove ith point (xi,yi) and reserve for testing.
  • Train the model on remaining points
  • Calculate Erri = I(yj≠ŷj)
  • Rinse and repeat
⋮ Return
CV(n) = 1 n∑ i=1nErr i
Setup: k-fold

  • Randomly split data into k-groups (folds)
  • Approximately equal sized. For the sake of notation, say each set has ℓ points
  • Remove ith fold Ui and reserve for testing.
  • Train the model on remaining points
  • Calculate Erri = 1 ℓ ∑ ⁡ (xj,yj)∈Ui I(yj≠ŷj)
  • Rinse and repeat

Return

CV(k) = 1 k∑ i=1kErr i
