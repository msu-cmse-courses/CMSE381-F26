Logistic regression

  • Assume single input 𝚇
  • Output takes values 𝚈 ∈{𝚈𝚎𝚜,𝙽𝚘}
p(𝚇) = Pr ⁡ (𝚈 = 𝚢𝚎𝚜∣𝚋𝚊𝚕𝚊𝚗𝚌𝚎)

p(𝚡) = eβ0+β1𝚡 1 + eβ0+β1𝚡

How to get logistic function

Assume the (natural) log odds (logits) follow a linear model
log ⁡ ( p(x) 1 −p(x) ) = β0 + β1x
Solve for p(x):
p(x) = eβ0+β1x 1 + eβ0+β1x
