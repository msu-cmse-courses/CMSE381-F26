Example 125 Regression bagging example.

For the shown data and bagged trees, predict the response for the new data point \(x_0\) (the yellow star).
🔗
Solution.
The predicted response for the new data point \(x_0\) is the average of the predictions from each bagged tree.
\begin{align*} \hat{f}_{\text{bag}}(x) \amp=\frac{1}{B}\sum_{b=1}^{B}\hat{f}^{*b}(x)\\ \amp= \frac{1}{3}(6.8 + 4.2+5.1)= 5.37 \end{align*}
