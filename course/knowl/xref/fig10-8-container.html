Putting It Together to Make a CNN.

  • Start with three channels.
    🔗
    🔗
  • Get a new channel at the first hidden layer for each filter. Use padding to keep the same size.
    🔗
    🔗
  • The next layer is a max pooling layer.
    🔗
    🔗
  • Convolve and pool several more times.
    🔗
    🔗
🔗
  • Since the size of the image decreases, increase the number of filters in the next convolution layer to compensate.
    🔗
    🔗
  • Flatten the result, then feed it into one or more fully connected layers.
    🔗
    🔗
  • The final layer uses a softmax activation for the 100 classes.
    🔗
    🔗
