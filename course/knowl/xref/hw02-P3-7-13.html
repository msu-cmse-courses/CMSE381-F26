Note 54.

A note on code. The book’s use of the ‘statsmodels’ package is slightly different from the examples provided in the Jupyter notebooks in class. In particular, in the book’s lab examples and in the homework statement they implicitly use import statsmodels.api as sm while we use import statsmodels.formula.api as smf.
🔗
This results in slight differences in code, in particular whether the function call you use is ‘OLS’ or ‘ols’. You may use whichever works for you, the answers should be the same.
