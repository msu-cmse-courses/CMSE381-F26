Checkpoint 114 Degrees of freedom.

The following tasks are related to the shown figure. Assume we are fitting a cubic polynomial over each segment.
🔗

(a)

For Figure (a), how many piecewise functions do we need to define?
🔗
Answer.
We have 3 segments, so we need 4 polynomials.
🔗
🔗
🔗

(b)

For Figure (a), how many coefficients do we need to fit in total? This is the degrees of freedom of the model with no constraints.
🔗
Hint 1.
A cubic polynomial requires fitting 4 constants: \(\beta_0 + \beta_1 X + \beta_2 X + \beta_3 X \text{.}\)
🔗
🔗
Hint 2.
We need to fit those coefficients for each function defined over each segment.
🔗
🔗
Answer.
We have 4 segments, and 4 coefficients over each segment, so we need to fit \(4\times4=16\) coefficients.
🔗
🔗
🔗

(c)

If we impose continuity and smoothness at the (interior) knots, how many constraints will we have to impose?
🔗
Hint 1.
Continuity means that \(f_{k-1}(X_k)=f_{k+1}(X_k)\) at any (interior) knot \(k\text{.}\)
🔗
🔗
Hint 2.
Smoothness means that we must require the first and second derivatives to be equal at the knots.
\begin{gather*} f'_{k-1}(X_k)=f'_{k+1}(X_k)\\ f''_{k-1}(X_k)=f''_{k+1}(X_k) \end{gather*}
🔗
🔗
Answer.
We have 3 interior knots with 3 constraints at each know, so we would impose \(3\times 3=9\) constraints.
🔗
🔗
🔗

(d)

What is the degree of freedom (DOF) for the model with the continuity and smoothness constraints?
🔗
Hint.
The DOF can be computed by finding the total number of degrees of freedom assuming no constraints, and then subtracting the number of constraints. in this case this gives \(16-9=7\text{.}\)
🔗
🔗
🔗

(e)

For Figure (b), what’s the DOF if we use cubic splines that satisfy continuity and smoothness at the (interior) knots?
🔗
Answer.
We have \(K\) interior knots, so the unconstrained model would have \(4(K+1)\) DOFs. However, we must subtract the required constraints to find the DOF for our model. With \(K\) knots, we would have \(3K\) constraints in total.
🔗
Therefore, \(\text{DOF}=4(K+1)-3K=K+4\text{.}\)
